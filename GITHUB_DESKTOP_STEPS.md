# Uploading this repository with GitHub Desktop

Your local GitHub project folder is `D:\GitHub`.

1. Extract the delivered ZIP file.
2. Move the extracted folder to:
   `D:\GitHub\EE3005_Image_Processing_Assignment_1`
3. Open **GitHub Desktop**.
4. Select **File > Add Local Repository...**.
5. Click **Choose...** and select:
   `D:\GitHub\EE3005_Image_Processing_Assignment_1`
6. If GitHub Desktop says the folder is not a Git repository, click **create a repository**.
7. Use these values:
   - Name: `EE3005_Image_Processing_Assignment_1`
   - Local path: `D:\GitHub`
   - Git ignore: `None` (a `.gitignore` is already included)
   - License: `None`
8. Click **Create Repository**.
9. In the left panel, verify the assignment files are listed under **Changes**.
10. In **Summary**, write: `Complete EE3005 Assignment 1`.
11. Click **Commit to main**.
12. Click **Publish repository** at the top.
13. Choose the repository name. Keep **Private** checked unless your instructor specifically requires a public repository.
14. Click **Publish Repository**.

After publishing, open the repository in your browser from **Repository > View on GitHub** and verify that `README.md`, `src/`, `data/`, `outputs/`, and `report/` are visible.
